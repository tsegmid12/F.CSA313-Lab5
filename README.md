# Lab 05 – API тест ба Newman автоматжуулалт

## Оюутны мэдээлэл

- **Оюутны нэр:** Э.Цэгмид
- **Оюутны код:** B232270107

## 1. Төслийн танилцуулга

Энэхүү лабораторийн ажлаар Node.js ашиглан боловсруулсан Course Registration REST API системийг Postman болон Newman хэрэгслээр тестэлсэн. API нь оюутан бүртгэх, хичээл бүртгэх болон оюутныг хичээлд бүртгэх үндсэн үйлдлүүдийг дэмжинэ. Postman collection ашиглан амжилттай хүсэлт, алдаатай хүсэлт болон серверийн холболтын алдааг шалгасан.

## 4. API спецификаци ба тестийн тохиолдлууд

Доорх хүснэгтэд API-ийн хүлээгдэж буй ажиллагааг харуулав.

| № | Тестийн тохиолдол | HTTP Status | Хүлээгдэж буй үр дүн |
|---|---|---:|---|
| 1 | Амжилттай бүртгэл (Happy Path) | 201 | `OK` |
| 2 | Идэвхгүй оюутан | 200 | `ERROR_INACTIVE_STUDENT` |
| 3 | Олдоогүй хичээл | 200 | `ERROR_NO_COURSE` |
| 4 | Урьдчилсан нөхцөл хангаагүй | 200 | `ERROR_PREREQUISITES` |
| 5 | CourseID байхгүй | 400 | `ERROR_BAD_REQUEST` |
| 6 | StudentID байхгүй | 400 | `ERROR_BAD_REQUEST` |
| 7 | Олдоогүй оюутан | 200 | `ERROR_NO_STUDENT` |
| 8 | Буруу JSON өгөгдөл | 400 | `ERROR_BAD_JSON` |
| 9 | Оюутан үүсгэх | 200 | `OK` |
| 10 | Хичээл үүсгэх | 200 | `OK` |
| 11 | Хичээлийн мэдээлэл авах | 200 | Хичээлийн мэдээлэл олдсон байна |
| 12 | Бүртгэлүүдийн мэдээлэл авах | 200 | Зөв бүтэцтэй бүртгэлийн хариу |

### Тестэд ашигласан жишээ өгөгдөл

| Оролтын утга | Жишээ |
|---|---|
| Идэвхтэй оюутны ID | `B231234567` |
| Идэвхгүй оюутны ID | `B231234568` |
| Хичээлийн ID | `CS313` |
| Бүртгэлийн endpoint | `POST /registrations` |
| Оюутан үүсгэх endpoint | `PUT /students/:id` |
| Хичээл үүсгэх endpoint | `PUT /courses/:id` |

Амжилттай бүртгэлийн тест нь хариуны `result` утга `OK` эсэх болон `registrationID` талбар байгаа эсэхийг шалгана. Бүртгэлийн ID-г тогтмол тоогоор шалгахгүй.

## 5. Тестийн цуглуулга

Үндсэн тестийн цуглуулга нь `lab05-collection.json` файлд байрлана.

Уг цуглуулга нь дараах 8 бие даасан тестийн тохиолдлыг агуулна:

1. Амжилттай бүртгэл (Happy Path)
2. Идэвхгүй оюутан (Inactive Student)
3. Олдоогүй хичээл (Course Not Found)
4. Урьдчилсан нөхцөл хангаагүй (Missing Prerequisite)
5. CourseID байхгүй (Missing CourseID)
6. StudentID байхгүй (Missing StudentID)
7. Олдоогүй оюутан (Student Not Found)
8. Буруу JSON өгөгдөл (Invalid JSON)

Шаардлагатай тохиолдлуудад эхлээд оюутан болон хичээлийн мэдээллийг үүсгэх тохиргооны хүсэлт илгээж, дараа нь бүртгэлийн хүсэлт болон хариуны шалгалтыг гүйцэтгэнэ.

## 6. Newman тестийн үр дүн

### 6.1 PASS тест

Ажиллуулах команд:

```powershell
newman run .\lab05-collection.json
```

| Үзүүлэлт | Үр дүн |
|---|---:|
| Гүйцэтгэсэн хүсэлт | 19 |
| Алдаатай хүсэлт | 0 |
| Гүйцэтгэсэн assertion | 37 |
| Амжилтгүй assertion | 0 |
| Newman exit code | 0 |

**Үр дүн:** PASS. Нийт 37 assertion бүгд амжилттай шалгагдсан.

Лог файл: `results/newman-pass.txt`

### 6.2 FAIL тест

Ажиллуулах команд:

```powershell
newman run .\lab05-collection-fail.json
```

FAIL цуглуулгад API-ийн хүлээгдэж буй үр дүнгийн утгуудыг зориудаар буруу болгож, шалгалтууд алдааг илрүүлж байгаа эсэхийг баталгаажуулсан.

| Үзүүлэлт | Үр дүн |
|---|---:|
| Гүйцэтгэсэн хүсэлт | 19 |
| Алдаатай хүсэлт | 0 |
| Гүйцэтгэсэн assertion | 37 |
| Амжилтгүй assertion | 7 |
| Newman exit code | 1 |

**Үр дүн:** FAIL тест хүлээгдэж буй байдлаар ажилласан. Зориудаар буруу болгосон 7 утгыг assertion амжилтгүй гэж илрүүлсэн.

Лог файл: `results/newman-fail.txt`

### 6.3 DOWN тест

Энэ тестийг гүйцэтгэхийн өмнө API серверийг зогсоосон.

Ажиллуулах команд:

```powershell
newman run .\lab05-collection.json
```

| Үзүүлэлт | Үр дүн |
|---|---:|
| Гүйцэтгэсэн хүсэлт | 19 |
| Алдаатай хүсэлт | 19 |
| Гүйцэтгэсэн assertion | 37 |
| Амжилтгүй assertion | 37 |
| Холболтын алдаа | `ECONNREFUSED` |
| Newman exit code | 1 |

**Үр дүн:** API сервер ажиллахгүй үед Newman холболтын алдааг зөв илрүүлсэн.

Лог файл: `results/newman-down.txt`

## 7. Алдааны шинжилгээ

Энэхүү лабораторийн ажлын хүрээнд тестийн хоёр өөр төрлийн алдааг шалгасан.

- **Assertion алдаа:** API хүсэлтэд хариу өгсөн боловч бодит хариу нь хүлээгдэж буй үр дүнтэй таарахгүй байхыг хэлнэ. Үүнийг FAIL цуглуулгад хүлээгдэж буй утгуудыг зориудаар буруу болгож харуулсан.
- **Холболтын алдаа:** API сервер ажиллахгүй эсвэл холболт тогтоох боломжгүй үед үүснэ. Үүнийг DOWN тестийн `ECONNREFUSED` алдаагаар харуулсан.

Assertion алдаа нь бодит болон хүлээгдэж буй үр дүнгийн зөрүүг илэрхийлдэг бол холболтын алдаа нь API серверт хүрч чадаагүйг илэрхийлнэ.

## 8. Дүгнэлт

Энэхүү лабораторийн ажлаар REST API тестлэх болон Newman ашиглан тестийг автоматжуулах арга барилыг судалж хэрэгжүүллээ. Хичээлд бүртгүүлэх API-ийн ажиллагааг шалгах 8 бие даасан тестийн тохиолдол боловсруулсан. Happy Path тестээр хүчинтэй оюутан хүчинтэй хичээлд амжилттай бүртгүүлж байгааг баталгаажуулсан. Сөрөг тестүүдээр идэвхгүй оюутан, байхгүй хичээл, хангагдаагүй урьдчилсан нөхцөл, дутуу ID болон буруу JSON өгөгдлийг шалгасан. PASS цуглуулгаар нийт 19 хүсэлт гүйцэтгэж, 37 assertion бүгд амжилттай болсон. FAIL цуглуулгад хүлээгдэж буй утгуудыг зориудаар буруу болгосноор 7 assertion амжилтгүй болж, алдааг илрүүлж байгааг баталсан. DOWN тестээр сервер ажиллахгүй үед Newman `ECONNREFUSED` алдааг илрүүлж байгааг шалгасан. Эдгээр үр дүн нь assertion алдаа болон холболтын алдааны ялгааг харуулж байна. Ийнхүү API тест болон Newman автоматжуулалтын үндсэн шаардлагуудыг амжилттай хэрэгжүүллээ.
