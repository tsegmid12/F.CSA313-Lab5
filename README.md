## Тестийн оролтын сонголтууд

| Хувьсагч | Утгууд | Тайлбар |
|---|---|---|
| Оюутны статус | `active`, `inactive`, байхгүй | Бүртгүүлэхийн өмнөх оюутны нөхцөл |
| Үзсэн хичээлүүд | шалгуур ханасан, хоосон, дурын | Урьдач нөхцөлийг хангасан эсэх |
| Хичээлийн урьдач нөхцөл | хоосон, `CS201` зэрэг байх | Хичээл бүртгүүлэх боломж |

| Хүсэлтийн JSON | зөв, оролт дутсан, бүтэн бус | JSON-ийн зөв эсвэл буруу формат |

## Тестийн спецификаци

| ID | Тестийн нөхцөл | Оюутны төлөв | Хичээлийн төлөв | Хүлээгдэх статус | Хүлээгдэх result |
|---|---|---|---|---|---|
| TC1 | Амжилттай бүртгэл | Идэвхтэй, CS201 үзсэн | Байгаа, урьдач CS201 | 201 | `OK` |
| TC2 | Оюутан байхгүй | Байхгүй | Байгаа | 200 | `ERROR_NO_STUDENT` |
| TC3 | Идэвхгүй оюутан | Идэвхгүй | Байгаа | 200 | `ERROR_INACTIVE_STUDENT` |
| TC4 | Хичээл байхгүй | Идэвхтэй | Байхгүй | 200 | `ERROR_NO_COURSE` |
| TC5 | Урьдач нөхцөл хангаагүй | Идэвхтэй, үзсэн хичээл хоосон | Байгаа, урьдач CS201 | 200 | `ERROR_PREREQUISITES` |
| TC6 | Буруу хүсэлт | Оролтод courseID дутуу | Бодит setup шаардахгүй | 400 | `ERROR_BAD_REQUEST` |
| TC7 | Урьдач нөхцөлгүй хичээл | Идэвхтэй | Байгаа, урьдач хоосон | 201 | `OK` |
| TC8 | Хоосон үзсэн хичээл | Идэвхтэй, хоосон | Байгаа, урьдач CS201 | 200 | `ERROR_PREREQUISITES` |
| TC9 | Буруу JSON | Хамааралгүй | Хамааралгүй | 400 | `ERROR_BAD_JSON` |
| TC10 | Давхар алдааны нөхцөл | Идэвхгүй | Байхгүй | 200 | `ERROR_INACTIVE_STUDENT` |

Тест бүр setup-г өөрөө үүсгэн, бие даасан байдлаар ажиллана. TC1-ийн `registrationID` утгын яг утгыг бүү мэдэхээр зөвхөн тоон утга байхыг шалгадаг. Тодорхой `registrationID` утга эсвэл `registrationID === N` хэлбэрийн assertion ашиглаагүй.

## Newman ажлын үр дүн

### FAIL ажиллуулалт

`lab05-collection-fail.json` тусдаа fail collection-оор зориудаар буруу oracle өгсөн.

```bash
newman run lab05-collection-fail.json 2>&1 | tee results/newman-fail.txt
```

- `assertions executed`: 1
- `assertions failed`: 1
- Exit code: 1
- Үр дүн: FAIL

### DOWN ажиллуулалт

Серверийг зогсоосны дараа доорх командыг ажиллуулсан.

```bash
newman run lab05-collection.json 2>&1 | tee results/newman-down.txt
```

- `ECONNREFUSED`: байгаа
- Exit code: 1
- Үр дүн: DOWN

`ECONNREFUSED` нь интерфейсийн алдаа бөгөөд серверт холбогдохгүй, HTTP хариу огт ирээгүй гэсэн үг. Oracle-ийн алдаа сервер ажиллаж HTTP хариу өгөх хэдий ч хариуны статус эсвэл утга хүлээгдэж буйгоос зөрөх явдал юм. Иймээс DOWN тестэд `ECONNREFUSED` нь холболтын орчны дутагдал, PASS/FAIL тестийн assertion mismatch нь oracle-ийн дүгнэлтийн алдаа билээ.

## Дүгнэлт

Энэхүү лабораторийн ажлаар курс бүртгэлийн API-ны үндсэн ба алдааны нөхцлийг системтэй шалгав.
Тестүүд эквивалент хуваалт болон хязгаарын утгууд дээр үндэслэн бичигдсэн.
Нэг нь амжилттай бүртгэл, бусад нь оюутан, хичээл, урьдач нөхцөл болон JSON оролтын алдааг хамарсан.
Тест бүр setup алхамаар шаардлагатай оюутан, хичээлийн төлөвийг бие даан бэлтгэдэг.
HTTP статус ба response-ийн `result` утгыг тусдаа assertion болгон шалгадаг.
TC1-д `registrationID`-ийн яг утгыг шалгахгүйгээр зөвхөн тоон төрөлтэй эсэхийг баталдаг.
Newman-ийн PASS бүртгэлд 22 assertion амжилттай, 0 failed, exit code 0 гарсан.
Тусдаа fail collection нь зориуд буруу oracle агуулж 1 assertion алдаатай, exit code 1 гаргасан.
Сервер зогссон үеийн DOWN тест нь ECONNREFUSED интерфейсийн алдаа, exit code 1 гарсан.
